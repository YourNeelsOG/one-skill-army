## Delivery contract

One project install command bundles OSA skills, adds host-native discovery
entries, and merges a concise automatic-routing instruction into project anchors.
The model selects matching skills from the user's request without requiring
setup-pstack or poteto-mode invocation. Existing model choices remain optional.
Default compression level is `ultra` (user choice, 2026-10-04).

## Ownership and prerequisites

Project installation writes inside the chosen project. It does not modify
user-wide host config, publish a package, or replace an unrelated skill.
Node.js and Python 3 are runtime prerequisites. npm packaging is verified
locally before any separately approved publication.
Native slash menus remain host dependent. Automatic activation uses project
instructions and discovery entries rather than relying on slash invocation.
